Katalog na dane wejściowe i wyjściowe — zawartość nie idzie do gita.

- `products-*.csv`   — eksport produktów ze sklepu (id;nazwa;producent;kolekcja;zdjecie;style;atrybuty)
- `kategorie-*.csv`  — eksport kategorii z BigQuery (short_id,name,type,subtype,...)
- `atrybuty.db`      — baza SQLite (produkty, findingi, decyzje, przebiegi)
- `eksport/`         — wygenerowane pliki poprawek i pliki cofające
